class-transformer


Variables de entorno: 

DB_PASSWORD=12345
DB_NAME=renta_peliculas
DB_HOST=localhost
DB_PORT=3310

1.- Clonar el repositorio
git clone https://github.com/f3rn4nd0l0/renta_peliculas_api.git
cd renta_peliculas_api

2.- Instalar dependencias
npm install

3.- Tomar el .env

Levantar el contenedor de tu mariaDB

4.- Ejecutar

npm run start:dev
